# web-evals 模块分析文档

## 1. API模块
### 1.1 任务接口
- 功能：创建和获取评估任务
- 文件：`src/app/api/tasks/route.ts`
- 示例：
  ```ts
  // 创建新任务
  POST /api/tasks
  ```

### 1.2 运行记录接口
- 功能：管理评估运行记录
- 文件：`src/app/api/runs/route.ts`
- 支持操作：创建、查询、删除运行记录

### 1.3 流式传输
- 功能：实时数据传输
- 文件：`src/app/api/runs/[id]/stream/route.ts`
- 技术：使用Server-Sent Events(SSE)

## 2. 运行管理模块
### 2.1 新建运行
- 功能：创建新的评估流程
- 文件：`src/app/runs/new/*`
- 包含：默认设置、运行配置、设置对比

### 2.2 运行状态
- 功能：监控评估进度
- 文件：`src/app/runs/[id]/run.tsx`
- 显示：连接状态、任务进度

### 2.3 任务状态
- 功能：跟踪单个任务
- 文件：`src/app/runs/[id]/task-status.tsx`
- 显示：任务完成情况、错误信息

## 3. UI组件库
### 3.1 表单组件
- 包含：输入框、选择器、多选等
- 位置：`src/components/ui/`

### 3.2 交互组件
- 包含：对话框、提示、抽屉等
- 示例：`src/components/ui/dialog.tsx`

### 3.3 布局组件
- 包含：页眉、滚动区、分隔线等
- 示例：`src/components/layout/header.tsx`

## 4. 工具函数
### 4.1 数据格式化
- 文件：`src/lib/formatters.ts`
- 功能：日期、数字等格式化

### 4.2 Schema定义
- 文件：`src/lib/schemas.ts`
- 功能：数据验证规则

### 4.3 实用函数
- 文件：`src/lib/utils.ts`
- 功能：通用工具方法
